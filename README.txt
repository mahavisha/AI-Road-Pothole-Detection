RoadAI Dashboard - Frontend files

1. Keep index.html, style.css, and script.js in the same folder.
2. Open index.html in VS Code.
3. Run with the Live Server extension, or open index.html in your browser.
4. Dashboard metrics and report rows are sample/demo values.
5. The image picker previews a selected image; AI inference is NOT connected yet.
   Connect the Run detection button to a Python Flask/API endpoint and trained model
   to produce real pothole detections.

Files:
- index.html : page structure and dashboard
- style.css  : responsive styling
- script.js  : image preview, drag-and-drop, and UI interactions
